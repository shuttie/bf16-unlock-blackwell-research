# Contributing

Corrections and reproductions are welcome. Open an issue or PR with:

- the experiment record (E number) or the exact command;
- the expected and observed output;
- the card, driver, and firmware versions if hardware is involved.

Do not upload NVIDIA firmware, driver binaries, decompiled firmware, vBIOS
dumps, or private keys. This repository ships text and tool source only.

By contributing, you agree that text contributions are CC BY 4.0 and code
contributions are MIT, except where a file's SPDX header says otherwise.
